## 2. Items Requiring New Data, Native Bridge, or Infrastructure Work

Flagged explicitly so UI implementation does **not** assume data that does not exist yet:

1. **ThumbHash Generation & Storage (for Instant Colored Placeholders & Memory Backdrops):**
   - *Gap:* `KeepsakeIndex.kt` SQLite schema has no `thumbhash` column, `LocalMediaReader.kt` only writes `.t`/`.p` JPEGs, and `KeepsakeLibrarySyncService.toSyncAsset` hardcodes `thumbhash: null`.
   - *Work required when prioritized:* Add `thumbhash TEXT` column + migration in `KeepsakeIndex.kt`, compute 25-byte ThumbHash in native Android/Rust during backup upload & index snapshot, expose over `keepsake_api.g.dart` `LibraryAsset`, and remove `ImageFilter.blur` fallback in `MemoryCard` once populated. *Until then, Milestone 1 uses shared `AmbryShimmerScope` + obsidian vignette (`MemoryCard`) with zero dependency on ThumbHash.*
2. **Per-Byte Telegram Upload Progress (`UploadDetailPage` & `BackupPage`):**
   - *Gap:* `ForegroundUploadService._backupToTelegram` currently fires `(0, 1)` and `(1, 1)`, producing `"1 B • ..."` in `UploadDetailPage`.
   - *Work required:* Emit TDLib `file.remote.uploadedSize` progress stream from `KeepsakeLibrary.kt` → Pigeon `EventChannel` / callback → `backupProvider` + `assetUploadProgressProvider`. *Until then, M2.2 displays `"Uploading…"` + asset file size rather than fake `"1 B"` counters.*
3. **Dark Vector Map Style URL (`MapPage` & `ExifMap`):**
   - *Gap:* `ServerInfoNotifier` assigns `'https://tiles.openfreemap.org/styles/liberty'` (light) to both `mapLightStyleUrl` and `mapDarkStyleUrl`.
   - *Work required:* Bundle or point `mapDarkStyleUrl` to a real dark OpenFreeMap / Positron dark style JSON and verify offline fallback.
4. **Offline Reverse Geocoding (`PlacePage`):**
   - *Gap:* `toSyncExif` sets `city/country/state: null`, leaving `PlacePage` empty.
   - *Work required:* Either bundle compact offline city polygon lookup (e.g. GeoNames cities15000 in Rust `native_core`) during sync, or route `LibraryPage`'s Places bento directly to `MapRoute` in M3.1 until geocoding lands.
5. **Security / Storage Follow-Up on Cronet 1 GiB Plaintext Cache:**
   - *Gap identified in Phase 1:* `MediaServer.kt:106` emits `Cache-Control: private, max-age=31536000, immutable` while `HttpClientManager.kt:326` caches 1 GiB plaintext HTTP responses in `cacheDir/cronet`, duplicating encrypted `ThumbnailStore`.
   - *Work required:* Evaluate changing `MediaServer.kt` `Cache-Control` to `no-store` for `127.0.0.1` (since `ThumbnailStore` + Flutter `CustomImageCache` already handle fast encrypted disk + in-memory caching) and clearing stale Cronet disk cache on logout/lock.
6. **Share Intent Upload Support (`ACTION_SEND`):**
   - *Gap:* `ForegroundUploadService.uploadShareIntent` rejects uploads for `_keepsakeLibrary != null`.
   - *Decision required in M4.3:* Either wire shared file paths through `keepsakeLibraryApiProvider.backupSharedFile(...)` or temporarily remove `ACTION_SEND`/`ACTION_SEND_MULTIPLE` from `AndroidManifest.xml` so Android doesn't advertise a broken share target.
