## 1. Architecture, Stack & Repo Conventions Verified

- **Framework & State:** Flutter (`>=3.47.0` / Dart `>=3.12.0`, `pubspec.yaml:8-9`), `hooks_riverpod` (`^2.6.1`), `auto_route` (`^11.1.0`, `lib/routing/router.dart`), Drift SQLite (`^2.34.0`), `flutter_displaymode` (`FlutterDisplayMode.setHighRefreshRate()`, `lib/main.dart:88`), `SystemChrome.setEnabledSystemUIMode(SystemUiMode.edgeToEdge)` (`lib/main.dart:167`).
- **Native Bridge (`lib/platform/`):** 11 Pigeon-generated APIs (`keepsake_api.g.dart` exposing `KeepsakeTelegramApi`, `KeepsakeVaultApi`, `KeepsakeLibraryApi`, plus 10 Immich native APIs: `background_worker_api.g.dart`, `background_worker_lock_api.g.dart`, `connectivity_api.g.dart`, `local_image_api.g.dart`, `native_sync_api.g.dart`, `network_api.g.dart`, `passkey_api.g.dart`, `permission_api.g.dart`, `remote_image_api.g.dart`, `view_intent_api.g.dart`).
- **Design System & Assets:**
  - Local `packages/ui/` (`immich_ui`) exports tokens (`ImmichSpacing`, `ImmichRadius`, `ImmichIconSize`, `ImmichDuration`, `ImmichElevation`, `ImmichBorderWidth`, `ImmichTextSize` in `packages/ui/lib/src/constants.dart`), `ImmichThemeProvider` / `ImmichColors` (`packages/ui/lib/src/theme.dart`), `SnackbarManager` (`packages/ui/lib/src/snackbar.dart`), `ImmichFormattedText`, and button/input/settings components.
  - Bundled fonts (`pubspec.yaml:131-151`): `GoogleSans` (400, 400 italic, 500, 600, 700) and `GoogleSansCode` (400, 500, 600).
  - Brand colors (`lib/constants/colors.dart:5-6`, `lib/theme/color_scheme.dart:6-14`): `immichBrandColorLight = #B8540F`, `immichBrandColorDark = #FDB44B`, mapped onto `ImmichColorPreset.indigo` (`colorfulInterface` defaults to `true` in `lib/domain/models/config/theme_config.dart`).
  - Logo (`keepsake/branding/ambry-logo.svg`, `keepsake/branding/generate_ambry_logo.py`): Arched alcove `#FFF6E6`, sun `#F9A825`, hills `#F08A2E` & `#B8540F`, background gradient `#FDB44B → #EE7F22`. Native splash (`flutter_native_splash.yaml`): light `#FFF6E6`, dark `#1C140D`, Android 12 icon tile `#F59A35`.
- **Architecture Rule (`keepsake/mobile/AGENTS.md`):** `lib/pages`, `lib/widgets`, `lib/services`, `lib/repositories`, `lib/entities` are legacy and must not grow; new shared UI primitives belong in `packages/ui/` (`immich_ui`) with previews in `packages/ui/lib/src/previews/`; new feature UI belongs in `lib/presentation/`.

## 5. Deep Dive A — Image & Video Loading Pipeline (Perceived Performance)

1. **`thumbHash` is ALWAYS `null` for Ambry Vault Assets:**
   - Verified in `keepsake_library_sync.service.dart:253` (`thumbhash: null`) and `KeepsakeIndex.kt:87-120` (no `thumbhash` column). `LocalMediaReader.kt` only generates encrypted JPEGs (`.t` 320px short side q80, `.p` 1440px long side q82 in `ThumbnailStore.kt`).
   - Result: `ThumbHashProvider` is unused; `Thumbnail.remote` generates trailing `&c=` params (`image_url_builder.dart:16`); `MemoryCard._BlurredBackdrop` (`memory_card.widget.dart:96-123`) always executes an expensive `ImageFilter.blur(sigmaX: 30, sigmaY: 30)` on full images.
2. **Encrypted Local Cache vs. Telegram On-Demand Fetch:**
   - Local assets (`asset.hasLocal && (!asset.hasRemote || !preferRemote) && !asset.isEdited`) load via `LocalThumbProvider` / `LocalFullImageProvider` → Pigeon `localImageApi`.
   - Vault assets resolve via `RemoteImageProvider` / `RemoteFullImageProvider` → Pigeon `remoteImageApi` → `RemoteImagesImpl.kt` (`CronetImageFetcher` + 2-thread `decodeExecutor`) → loopback `MediaServer.kt` (`127.0.0.1:47819`, 8 worker threads).
   - **Warm cache (`ThumbnailStore`):** Decrypts `.t`/`.p` using AES-256-GCM (`VaultCrypto.open`) — fast (<50ms).
   - **Cold restore (`KeepsakeIndex.kt:295` resets `has_thumbnail = 0`):** `KeepsakeLibrary.image()` (`KeepsakeLibrary.kt:258-270,626-638`) checks `requireTelegram()` (HTTP 500 if TDLib not ready), enters **`Semaphore(2)`**, and for **images downloads & decrypts the entire original file** from Telegram to generate `.t`/`.p`!
   - **Security/Storage Flag:** `MediaServer.kt:106` emits `Cache-Control: private, max-age=31536000, immutable` while `HttpClientManager.kt:326` configures a **1 GiB plaintext Cronet disk cache** (`cacheDir/cronet`) — storing unencrypted copies alongside encrypted `ThumbnailStore`.
3. **Placeholder, Fade & Error Gaps:**
   - **Grid (`Thumbnail`):** Static `surfaceContainer → darken(0.1)` gradient, `100ms` `Curves.easeOut` fade (`thumbnail.widget.dart:267,281`), `FilterQuality.low`. On error (`:128-131`), stops stream and stays **permanently blank** with no retry. `didUpdateWidget` (`:161`) fails to clear stale `_providerImage`.
   - **Viewer Photos (`AssetPage`):** Shows `initialImage` synchronously (`photo_view_wrappers.dart:136-149`), hiding `loadingBuilder` while waiting seconds for `.p`/original from Telegram. If final stage fails offline (`asset_page.widget.dart:393-397`), destroys the preview and disables zoom with no error/retry UI. `AssetPreloader` (`asset_preloader.dart`) preloads both neighbors after `400ms` — saturating TDLib if `loadOriginal == true`.
   - **Viewer Videos (`NativeVideoViewer`):** Remote playback streams encrypted 1 MiB segments via `RemoteAssetReader` (`24 MiB` LRU) + per-file `Mutex` in `TdClient.downloadRange` (`300s` timeout), taking ~4s to start (`docs/PRODUCTION_READINESS.md:46`). UI shows `showingControls: false` + `200ms` swipe delay + `1000ms` `_bufferingTimer` + `400ms` spinner fade = **1.2s–1.6s dead silence** before any loading cue, then spins forever on failure.
